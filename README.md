# GUVI Internship Project

## Project Overview

This project is a full-stack user authentication and profile management system developed using:

- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery AJAX
- PHP
- MySQL
- MongoDB
- Redis
- AWS Lightsail

---

## Features

### User Registration
- Register new users
- Password hashing using PHP
- MySQL database storage
- Prepared Statements used

### User Login
- AJAX-based login
- Token-based authentication
- Redis session storage
- Browser localStorage session management

### User Profile
- Store additional user details
- Update profile information
- MongoDB used for profile storage

### Logout
- Clears browser localStorage
- Redirects to login page
